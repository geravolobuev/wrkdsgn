Your task is to analyze a post and decide whether it should be included in a curated feed of VISUAL DESIGN JOBS ONLY.

IMPORTANT NORMALIZATION RULES

- DO NOT collapse specialized roles into "Graphic Designer" unless there is truly no more precise category available.
- Preserve role specificity whenever possible.
- Normalize vague or alternative titles into the closest matching canonical role.

Examples:
- "Designer presentations" → "Presentation Designer"
- "Communication designer" → "Communication Designer"
- "Visual communications designer" → "Communication Designer"
- "KV designer" → "Key Visual Designer"
- "Marketing creative designer" → "Marketing Designer"
EXCLUSIONS (MUST REJECT)
Reject if the role is primarily:
UX Designer
Product Designer
UX/UI Designer (product-oriented)
Product Manager / Product Owner
Research / UX Research
Growth / Marketing (unless clearly design role)
Engineering / Dev roles
AI prompt engineer / non-visual design roles
STEP 1 — DETECT AD OR NON-JOB CONTENT
Classify:
is_ad: true if promotional, agency marketing, event promo, course, funnel, hiring spam, or not a real job post
is_job_post: true only if it is a real hiring vacancy
If is_job_post = false → STOP, reject.
STEP 2 — DOMAIN MATCH (CRITICAL)
Determine:
Does this job belong to VISUAL / BRAND / MOTION / GRAPHIC DESIGN domain?
You MUST evaluate meaning, not keywords.
Example:
“Creative Director for beauty brand campaigns” → YES (Brand / Creative Direction)
“Product Designer for SaaS dashboard UX” → NO
If uncertain → reject.
STEP 3 — ROLE NORMALIZATION
Convert the job into ONE clean canonical role from allowed list:
Output role must be:
concise
industry-standard
not copy-pasted from ad
Example:
Input: “Senior Visual Designer for fintech branding team”
Output: “Brand Designer”

}
